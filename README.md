# vectros-feedback

The public issue tracker for Vectros: bug reports and feature requests for the SDKs, the MCP
server, the CLI, the reference apps, the examples, and the API spec. No code lives here.

- **Bug or feature request:** [open an issue](https://github.com/vectros-ai/vectros-feedback/issues/new/choose).
- **Security vulnerability:** do not open an issue. Follow the
  [security policy](https://github.com/vectros-ai/.github/blob/main/SECURITY.md).
- **How to use Vectros:** [docs.vectros.ai](https://docs.vectros.ai).

The code repositories in this organization are release mirrors, so issues for all of them are
tracked here. See the [contributing guide](https://github.com/vectros-ai/.github/blob/main/CONTRIBUTING.md).
